# Catalogue data corrections

A public record of corrections to panel and controller data in Solar Pear (roadmap 6.6). New products are not listed here, only changes to figures, links or compatibility that users may have relied on.

To report an error, use "Report a data error" in a product's information panel, or open a [data correction issue](https://github.com/GryphonR/Solar-Pear/issues/new?template=data-correction.yml). Please include a link to the datasheet.

Newest first.

| Date | Product | Change | Why |
| ---- | ------- | ------ | --- |
| 2026-09-30 | Victron BlueSolar Mono 185 W | Discontinued; saved designs move to the BlueSolar Mono 190 W | Replaced by the manufacturer |
| 2026-09-30 | Victron BlueSolar Mono 150 W | Efficiency stored as 15.1% (from size and power) rather than the 18.9% on the datasheet | The datasheet figure contradicts its own dimensions |
| 2026-09-25 | Voltacon SGM2-180W | Efficiency corrected to the module figure | Datasheet value quoted was cell efficiency |
| 2026-09-25 | Voltacon VS-FL-200-M36-E | Efficiency corrected to the module figure; no longer marked GSE in-roof compatible | Cell efficiency had been quoted; a flexible panel cannot fit a GSE tray |
| 2026-09-25 | OutBack FLEXmax 100-300 | Maximum PV operating current cleared | The field held the 100 A battery charge current |
| 2026-09-25 | 28 MPPT chargers | Battery charge current moved out of the PV input current field into its own field | PV current checks were using the battery-side rating |
| 2026-09-25 | Trina (one record) | Buy link to a retailer's development site removed | Link pointed at a test site category page |
